## 🎯 О проекте

Одностраничный HTML-тренажёр, составленный по **спецификации, кодификатору и демоверсии ФИПИ ЕГЭ-2027 по немецкому языку**. Работает полностью офлайн — достаточно открыть `index.html` в браузере.

Никаких серверов, аккаунтов, рекламы и аналитики. Все ответы и чек-лист сбрасываются при обновлении страницы.

## ✨ Возможности

- 📝 **42 задания** по структуре ЕГЭ-2027:
  - Аудирование (1–9) — 12 баллов;
  - Чтение (10–18) — 12 баллов;
  - Грамматика и лексика (19–36) — 18 баллов;
  - Письменная речь (37–38) — 20 баллов;
  - Устная часть (39–42) — 20 баллов.
- 🎧 **Аудирование** с встроенным плеером (`audio-de.mp3`) и отдельным аудио для устной части (`audio-de-oral.mp3`).
- 🔍 **Фильтры по разделам**: аудирование / чтение / грамматика / письмо / устная часть.
- ⏱ **Таймер экзамена** с пресетами: 190 / 17 / 30 / 40 / 90 минут.
- ✅ **Частичная автопроверка** последовательностей (каждая ошибка −1 балл, но не ниже 0).
- 🇩🇪 **Поддержка умлаутов и ß**: ä/ae, ö/oe, ü/ue, ß/ss — всё принимается.
- 📊 **Счётчик слов** для заданий 37 и 38 с цветовой индикацией нормы.
- 👁 **Показать все ключи** одной кнопкой.
- 📋 **Чек-лист подготовки** по всем темам.
- 🗓 **25-дневный план** повторения.
- 📱 **Адаптивный дизайн**.
- 🔒 **100% офлайн**, без рекламы и трекеров.
